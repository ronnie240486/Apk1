# PrimeX — correção efetiva de layout e categorias

A captura do aparelho mostrou que as tentativas anteriores chegavam à grade, mas o cabeçalho original se sobrepunha e os grupos não apareciam. A revisão usa uma faixa única para `main_info`, com uma linha truncada e alinhada no topo. No fluxo autorizado, a lista Live original é atualizada depois do retorno assíncrono: `ga.d.a()` reconstrói o mapa global de grupos; o fragmento Live é verificado quanto à view inflada; o adaptador antigo é limpo quando necessário; `ka/r.Z()` monta os grupos e `ka/r.c0()` atualiza canais. A operação é repetida por até 12 ciclos de 750 ms se o provedor ainda estiver terminando o preenchimento dos dados.

O monitor Prestige continua consultando a cada cinco segundos enquanto aguarda autorização. A ponte `AuthInfo`, o botão Home, `main_vp`, a playlist e as proteções null-safe permanecem no APK.
