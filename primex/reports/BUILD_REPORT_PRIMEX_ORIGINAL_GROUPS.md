# PrimeX — categorias originais restauradas

A versão anterior já recebia autorização e canais, mas a coluna de categorias não era reconstruída antes da troca para a tela principal. A revisão atual chama `ga.d.a()` para reconstituir o mapa de grupos a partir da lista carregada, verifica que a view Live foi inflada, marca o fragmento como pronto, chama `ka/r.Z()` para montar o adaptador de grupos e `ka/r.c0()` para atualizar a categoria selecionada. Também marca o botão Home e mantém o pager principal `main_vp`.

A tela original `fragment_live` continua sendo usada com `vg_group` para categorias, `rv_channel` para canais e `epg_listview` para EPG. A ativação MAC e o monitor Prestige de cinco segundos permanecem inalterados.
